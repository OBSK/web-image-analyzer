# Image Analyzer

Aplicación fullstack que permite analizar imágenes utilizando inteligencia artificial y obtener etiquetas descriptivas con su nivel de confianza.

---

## 🚀 Stack

- **Frontend:** Next.js, Tailwind CSS  
- **Backend:** Node.js, AWS Lambda, Serverless Framework  
- **IA:** Google Cloud Vision API  
- **Rate limiting:** Upstash Redis
